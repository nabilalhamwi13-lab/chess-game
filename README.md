# ♟️ Erweitertes Schachspiel

Ein interaktives Schachspiel mit vollständigen Regeln, Schach/Schachmatt-Erkennung und Zugverlauf.

## 🎮 Jetzt spielen!

## ✨ Features

- ♔ **Rochade (Castling)** - Königs- und Damenseite
- 🎯 **En Passant** - Spezielle Bauernzugregel  
- 👑 **Schach & Schachmatt-Erkennung** - Mit Status-Anzeige
- 📋 **Zugverlauf** - Alle Züge in algebraischer Notation
- ↩️ **Zug zurück** - Mit vollständiger Spielzustand-Restauration
- 🎨 **Verbesserte UI** - Mögliche Züge anzeigen, letzte Züge hervorheben
- 👸 **Bauernumwandlung Modal** - Wahl zwischen Dame, Turm, Läufer, Springer

---

## 🎮 Wie man spielt

### Grundlagen
1. **Figur auswählen**: Klick auf eine deiner weißen/schwarzen Figuren
2. **Zug machen**: Klick auf das Zielfeld (grüne Punkte zeigen erlaubte Züge)
3. **Abwählen**: Nochmal auf die gleiche Figur klicken

### Spezielle Züge
- **Rochade**: König und Turm bewegen sich zusammen (nur wenn beide noch nicht gezogen haben)
- **En Passant**: Spezielle Bauernzugregel für diagonales Schlagen
- **Bauernumwandlung**: Wenn ein Bauer die letzte Reihe erreicht, wähle eine neue Figur

### Buttons
- **Neues Spiel** - Startet eine neue Partie
- **Zug zurück** - Macht den letzten Zug rückgängig

---

## 📖 Schachregeln

Dieses Spiel implementiert die vollständigen FIDE-Schachregeln:

- Alle 6 Figurentypen (Bauer, Turm, Springer, Läufer, Dame, König)
- Legale Zugbeschränkungen pro Figurentyp
- Schach und Schachmatt-Erkennung
- Rochade (mit den korrekten Bedingungen)
- En Passant
- Bauernumwandlung
